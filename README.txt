IATE TÊNIS CLUBE — PROTÓTIPO HTML
===================================

Páginas incluídas:
- index.html       Portal de entrada
- dashboard.html   Backoffice dashboard
- socios.html      Gestão de sócios
- portaria.html    Controle de portaria
- financeiro.html  Financeiro e mensalidades
- convites.html    Emissão de convites
- quadras.html     Reserva de quadras
- marina.html      Gestão náutica com mapa de vagas clicável
- app-socio.html   Prévia visual do app do sócio
- assets/styles.css
- assets/app.js

COMO ABRIR
1. Extraia o ZIP.
2. Abra index.html no navegador.
3. Navegue pelos módulos usando o menu/cartões.

IMPORTANTE
Este é um protótipo visual com dados fictícios. Formulários, botões e filtros têm
interações demonstrativas no navegador; não há banco de dados, login, pagamentos
ou API conectados. Para produção, integrar ao backend e implementar autenticação,
permissões, validação e persistência de dados.
